# RF Next Companion 2.0.0-beta.39

Instalador imutável da versão beta.39 do RF Next Companion para Windows x64.

Esta versão mantém o nome e o nível do personagem na tela quando atualizações
parciais chegam para o mesmo UID, sem reaproveitar dados após uma troca real de
personagem.

O manifesto Ed25519 está em `update-manifest.json`; `latest.json` é uma cópia
para validação isolada desta branch.
