# RF Next Companion 2.0.0-beta.34

Instalador imutável da versão beta.34 do RF Next Companion para Windows x64.

Esta versão atualiza o decoder do Agent com Power na rota TCP 12040,
MAU/Launcher, ranking de contribuição e avisos de itens, preservando os filtros
existentes de loot, alvos e combate.

O manifesto Ed25519 está em `update-manifest.json`; `latest.json` é uma cópia
para validação isolada desta branch.
