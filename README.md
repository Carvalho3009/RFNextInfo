# RF Next Companion 2.0.0-beta.25

Instalador público do RF Next Companion para Windows x64.

- elimina observações idênticas de personagem e power antes da fila offline;
- mantém eventos imediatos à frente sem bloquear Mercado, Ranking e demais dados;
- preserva eventos pendentes, confirmações idempotentes e o contrato do servidor;
- mantém Boss e PvP somente na API local.

O projeto não usa Authenticode. Confira `SHA256SUMS.txt` antes de executar.
