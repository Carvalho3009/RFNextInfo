# RF Next Companion 2.0.0-beta.35

Instalador imutável da versão beta.35 do RF Next Companion para Windows x64.

Esta versão distingue os rankings de contribuição das facções Accretia,
Bellato e Cora e separa lista completa de posição própria.

O manifesto Ed25519 está em `update-manifest.json`; `latest.json` é uma cópia
para validação isolada desta branch.
