# RF Next Companion 2.0.0-beta.31

Instalador imutável da versão beta.31 do RF Next Companion para Windows x64.

Esta versão melhora as fotografias de Inventário, Equipamentos e Coleção/Códex,
mantendo a separação entre instalações e personagens e preservando snapshots
pendentes quando a fila offline falha durante a gravação.

O manifesto Ed25519 está em `update-manifest.json`; `latest.json` é uma cópia
para validação isolada desta branch.
