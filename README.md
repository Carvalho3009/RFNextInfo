# RF Next Companion 2.0.0-beta.37

Instalador imutável da versão beta.37 do RF Next Companion para Windows x64.

Esta versão envia ao site as listas completas top 100 de contribuição das
facções Accretia, Bellato e Cora, sem expor UIDs ou campos internos.

O manifesto Ed25519 está em `update-manifest.json`; `latest.json` é uma cópia
para validação isolada desta branch.
