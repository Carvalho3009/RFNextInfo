# RF Next Companion beta.75

Corrige a atribuição de kills nas subsessões de Farm quando a identidade do personagem foi recuperada após uma atualização. Preserva a correção de horário da beta.74: a última confirmação do servidor aparece no horário de Brasília (UTC−3), independentemente do fuso configurado no Windows.

No Companion, use **Verificar atualização**. O pacote também mantém os leitores e correções anteriores, incluindo os nomes no DPS. Replay real, testes de autoria e horário, regressão completa, autoteste e ensaio isolado do instalador foram executados. A confirmação de kills em uma nova subsessão real depende da instalação desta atualização.
