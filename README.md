# RF Next Companion 2.0.0-beta.33

Instalador imutável da versão beta.33 do RF Next Companion para Windows x64.

Esta versão corrige a correlação de equipamentos entre rotas TCP do mesmo
cliente lógico, preservando a separação entre clientes e permitindo ao site
identificar corretamente os itens equipados.

O manifesto Ed25519 está em `update-manifest.json`; `latest.json` é uma cópia
para validação isolada desta branch.
