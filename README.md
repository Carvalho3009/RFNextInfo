# RF Next Companion 2.0.0-beta.23

Instalador Windows x64 da edição beta do Companion.

- captura e decode locais;
- envio das informações permitidas ao servidor dedicado;
- API local somente leitura para Boss e PvP;
- correção da confirmação de personagens, kills PvE e loadout equipado;
- novo nome e ícone RF Next Companion;
- atualização compatível com a instalação anterior do RF QOL Agent.

O projeto não usa Authenticode. Consulte `UNSIGNED-NOTICE.txt` antes de
executar e compare o hash publicado em `SHA256SUMS.txt`.
