# RF Next Companion 2.0.0-beta.38

Instalador imutável da versão beta.38 do RF Next Companion para Windows x64.

Esta versão exibe na tela do Companion a identidade estável de cada Agent,
mantendo a conta vinculada separada e sem expor credenciais.

O manifesto Ed25519 está em `update-manifest.json`; `latest.json` é uma cópia
para validação isolada desta branch.
