# RF Next Companion 2.0.0-beta.26

Instalador público do RF Next Companion para Windows x64.

- reforça a confirmação e o isolamento do personagem por conexão;
- envia trocas de mapa confirmadas com o horário original do evento;
- separa equipamento de itens empilháveis sem perder uma categoria;
- recompõe deltas de inventário e atualiza o loadout pelo UID exato;
- mantém Boss e PvP somente na API local.

O projeto não usa Authenticode. Confira `SHA256SUMS.txt` antes de executar.
