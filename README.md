# RF Next Companion 2.0.0-beta.28

Instalador imutável da versão beta.28 do RF Next Companion para Windows x64.

Esta versão preserva no envio automático do Mercado os itens cujo jogo informa
o maior preço como zero, usando o menor preço válido como limite superior. Isso
evita que anúncios válidos, como `Pioneer's Erebus Blade +5`, desapareçam antes
de chegar ao site.

O manifesto Ed25519 está em `update-manifest.json`; `latest.json` é uma cópia
para validação isolada desta branch.
