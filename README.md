# RF Next Companion 2.0.0-beta.24

Instalador público do RF Next Companion para Windows x64.

- impede que jogadores próximos substituam a identidade confirmada do cliente;
- ignora perfis remotos sem nome confirmado;
- mantém personagens, sessões e subsessões separados por cliente;
- preserva a captura e o decode locais, com Boss e PvP somente na API local.

O projeto não usa Authenticode. Confira `SHA256SUMS.txt` antes de executar.
