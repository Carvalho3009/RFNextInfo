# RF Next Companion 2.0.0-beta.32

Instalador imutável da versão beta.32 do RF Next Companion para Windows x64.

Esta versão envia ao site fotografias consolidadas de encontros de Boss com
Chefe, HP e dano total por personagem, preservando o monitor local e mantendo
golpes brutos e PvP fora do servidor.

O manifesto Ed25519 está em `update-manifest.json`; `latest.json` é uma cópia
para validação isolada desta branch.
