# RF QOL Agent 2.0.0-beta.22

Instalador Windows x64 da edição beta do Agent.

- captura e decode locais;
- envio das informações permitidas ao servidor do Agent;
- API local somente leitura para Boss e PvP;
- atualização baixada automaticamente, validada por assinatura Ed25519,
  tamanho e SHA-256;
- reinício e abertura do instalador somente após confirmação visível.

O projeto não usa Authenticode. Consulte `UNSIGNED-NOTICE.txt` antes de
executar e compare o hash publicado em `SHA256SUMS.txt`.
