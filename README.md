# Canal beta do RF Next Companion

`latest.json` é um manifesto Ed25519. O instalador apontado permanece na branch imutável da versão.

Este canal não contém código-fonte nem chave privada.

Versão atual: `2.0.0-beta.47` (sequência 57).

[Baixar instalador](https://raw.githubusercontent.com/Carvalho3009/RFNextInfo/download/rf-qol-agent-2.0.0-beta.47/RF-Next-Companion-Setup-2.0.0-beta.47.exe)

Recuperação segura de colisões de sequência, identificação de conflitos de envio
e manutenção explícita com backup. A atualização não apaga filas automaticamente.
Testes automáticos e instalador validados; homologação física no Windows 10
afetado continua pendente. Beta.46 e o feed anterior permanecem disponíveis
para reversão manual; restaurar o feed não faz downgrade de instalações.
