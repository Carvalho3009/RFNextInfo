# RF Next Companion 2.0.0-beta.27

Instalador imutável da versão beta.27 do RF Next Companion para Windows x64.

Esta versão adiciona a API local consolidada de encontros de Boss para o
Monitor de Boss e o painel do Discord. O manifesto Ed25519 está em
`update-manifest.json`; `latest.json` é uma cópia para validação isolada desta
branch.
