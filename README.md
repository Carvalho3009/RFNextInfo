# RF Next Companion 2.0.0-beta.36

Instalador imutável da versão beta.36 do RF Next Companion para Windows x64.

Esta versão recupera snapshots de equipamentos quando as conexões TCP do
mesmo cliente ainda não foram associadas, preservando o isolamento entre
clientes já identificados.

O manifesto Ed25519 está em `update-manifest.json`; `latest.json` é uma cópia
para validação isolada desta branch.
