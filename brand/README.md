# Kit de marca Karvalho

## Entregas

- `manual/Karvalho-Manual-de-Marca.pdf`: manual completo de identidade.
- `logos/png/karvalho-primary-gold.png`: assinatura principal para fundos escuros.
- `logos/png/karvalho-symbol-gold.png`: símbolo para avatar, favicon e espaços quadrados.
- `logos/png/karvalho-wordmark-gold.png`: nome isolado para faixas e assinaturas.
- `logos/png/karvalho-stacked-gold.png`: composição vertical.
- `logos/png/karvalho-primary-white.png`: versão monocromática clara.
- `logos/png/karvalho-primary-black.png`: versão monocromática escura.
- `references/`: conceito aprovado e linguagem visual de apoio.
- `tokens/karvalho-colors.css`: cores oficiais em formato reutilizável.

Todos os PNGs finais possuem fundo transparente. Os arquivos em `logos/source/` conservam o fundo técnico usado durante a extração e não devem ser publicados.

## Regra rápida

Use a versão dourada sobre carvão. Use branco em fundos escuros quando o dourado perder detalhe e preto em fundos claros. Nunca redigite o nome, distorça a proporção ou reproduza personagens, logos e interfaces de franquias usadas como referência cultural.
