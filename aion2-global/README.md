# AION 2 Global

Projeto editorial em português para produzir um guia de *AION 2* no servidor Global, usando o guia do ROOC Americas como molde de organização — nunca como fonte factual.

O conteúdo fica em [`conteudo`](./conteudo/README.md).

## Escopo inicial

- guia geral;
- fichas de classes;
- plano da primeira semana;
- sistemas e decisões de investimento;
- FAQ e glossário;
- matriz de validação regional.

Site, mockup e automação estão fora desta primeira fase.
